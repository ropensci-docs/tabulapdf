# tabulapdf

Bindings for “Tabula” PDF Table Extractor Library

## Details

Tabula is a Java library designed to computationally extract tables from
PDF documents. tabulapdf provides a thin R package with bindings to the
library. It presently offers two principal functions:
[`extract_tables`](https://docs.ropensci.org/tabulapdf/reference/extract_tables.md),
which mimics the command line functionality of Tabula, and
[`extract_areas`](https://docs.ropensci.org/tabulapdf/reference/extract_areas.md)
which provides an interactive interface to the former.
